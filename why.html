Why OpenWin

A picker, not another installer

OpenWin helps you choose a set of Windows apps and gives you the winget commands. It does not download, bundle, or run anything itself.

Last updated: 10 November 2026

What you get

  • A fixed catalog of 231 apps in 11 categories.
  • One exact winget install command per selected app.
  • The full command block before you copy or run anything.
  • Search across names, publishers, package IDs, descriptions, categories, and source labels.
  • A shareable selection stored in the URL fragment.
  • No account, no analytics, and no advertising.

How it differs from Ninite

Ninite is a separate proprietary service that downloads and installs the apps you pick. OpenWin is an open-source static site that only generates commands for winget. It is not affiliated with Ninite, and it does not use Ninite's installers or catalog.

How it differs from searching winget yourself

winget search returns live search results, which can include similar names or multiple packages from the same publisher. OpenWin uses exact package IDs from a fixed catalog, so the command you copy points at the package the catalog lists. The tradeoff is that OpenWin is not a live mirror of winget. New apps and changes arrive through repository updates.

Why the catalog is fixed

A fixed catalog is easier to review, test, and keep predictable. Every app has a name, publisher, description, homepage, category, source, and icon. The site shows when the package IDs were last checked. It does not claim that the catalog is complete or that every app is right for every PC.

What it does not do

  • It does not install, update, or uninstall apps for you.
  • It does not run commands in the background.
  • It does not bundle installers or offers.
  • It does not require an account or collect analytics.
  • It does not verify that an app is malware-free or safe.

Who it is for

OpenWin is for people who know roughly which apps they want on a fresh Windows install and would rather copy a short command list than click through a series of download wizards. It is also useful when you want to send someone a reproducible list of apps.
