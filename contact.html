Contact and feedback

Email is the simplest way to reach me. GitHub Issues is better for catalog corrections and app suggestions that other people may want to follow.

Last updated: 10 November 2026

Email: fsamod@proton.me

There is no contact form on this site. A GitHub account is required to open an issue.

Email

Use email for general questions, privacy concerns, or security reports. Do not send passwords, keys, or other secrets.

GitHub Issues

Use the new issue form to open a catalog correction, app suggestion, or general bug report. You can also browse existing issues before opening a new one.

Report a catalog problem

Include as much of the following as you can:

  • The app name and package ID shown in the details dialog.
  • Whether the source is winget or the Microsoft Store.
  • What is wrong, for example a broken homepage, wrong publisher, or wrong category.
  • Your Windows version and winget version, if the problem involves installing.

Suggest an app

Include the official name, publisher, package ID, source, and homepage. A package ID that resolves in winget or the Microsoft Store is the minimum. Explain why the app belongs in the fixed catalog and whether it is stable or a beta release.

Security reports

Email fsamod@proton.me with the affected page or file, steps to reproduce, and the impact you believe it has. Do not open a public issue with exploit details or personal data.

If GitHub private vulnerability reporting is available on the repository's Security tab, you can use that instead.

Please do not send

  • Passwords, keys, or other secrets.
  • Exploit details in a public issue.
  • Personal data you do not want stored in GitHub or email.
