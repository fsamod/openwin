Security

Security

OpenWin checks its own catalog and command generation. It does not verify that an app is safe, and it does not replace winget or the Microsoft Store.

Last updated: 10 November 2026

What OpenWin checks

  • Package IDs must match a restricted character set before a command is generated.
  • Every catalog entry uses the winget or msstore source.
  • The catalog was checked against winget 1.29.380 on 9 November 2026. Every package ID resolved at that time.
  • Icons are served from this site. The app picker makes no third-party requests.
  • Commands are generated in your browser and shown before you copy them.

Resolving a package ID means winget or the Microsoft Store recognizes it. It does not mean the package is safe, current, or suitable for you.

What OpenWin does not check

  • Package contents, installers, or downloaded files.
  • Publisher identity beyond the metadata shown in the catalog.
  • Malware, viruses, or unwanted behavior.
  • Licenses, privacy practices, or update policies.
  • Microsoft Store certification or winget manifest review.
  • Homepage content or whether a description is complete.

OpenWin does not claim that any app is malware-free or independently security-verified.

What winget and the Microsoft Store do

winget reads package manifests from configured sources and downloads installers from the locations in those manifests. The Microsoft Store source uses Microsoft's Store infrastructure. Each source has its own validation and policy processes, and some installers are signed while others are not. OpenWin does not add to or replace those checks.

What the generated command does

winget install --id "Brave.Brave" --source winget --exact --accept-package-agreements --accept-source-agreements --disable-interactivity
  • --id and --exact select the exact package ID instead of a search result.
  • --source selects the winget or Microsoft Store source.
  • --accept-package-agreements and --accept-source-agreements accept the publisher and source agreements when the command runs. Review those agreements before you run it.
  • --disable-interactivity prevents interactive prompts during the install.

OpenWin never runs these commands. Your browser cannot run winget. The command changes your PC only when you paste it into a terminal and run it.

Site security

  • The site is static and has no backend, accounts, database, or file uploads.
  • The production build adds a Content Security Policy that restricts scripts to this origin and blocks forms.
  • GitHub Pages does not support custom response headers, so some headers cannot be set by this project. The meta policy is a practical fallback, not a complete server configuration. In particular, it cannot restrict framing, so framing protection depends on the browser and host.
  • Dependencies are kept small and checked with npm audit.
  • Catalog and command-generation tests run in CI before deployment.

Reporting a security issue

Email fsamod@proton.me with the affected page or file, steps to reproduce, and the impact you believe it has. Do not open a public issue with exploit details or personal data.

If GitHub private vulnerability reporting is available on the repository's Security tab, you can use that instead. Do not test against systems you do not own.
