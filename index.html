How it works

Pick the apps you want and copy one exact winget install command for each. Every command is visible before you copy it, and nothing runs until you paste it into Windows Terminal.

Commands use exact package IDs and point at the right source. They accept the source and package agreements, so winget does not stop to ask. No account, no analytics, no bundled offers.
