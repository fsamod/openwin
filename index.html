About OpenWin

by fsamod

OpenWin is a free, open-source app catalog for Windows. Browse thousands of winget packages, choose the apps you need, and copy a single command to install them yourself.

No accounts, no tracking, and no custom installers. OpenWin generates commands for you to inspect and run on your own PC.

Built by fsamod. Package metadata comes from Microsoft's community winget-pkgs repository.
